Z App Icon Pack

Original artwork provided by the user. Removed the dark background and bottom-right sparkle; preserved the glossy gradient and white Z mark.

Files:
- z-app.png: 1024x1024 RGBA (transparent) master
- png/z-app-512.png etc: Linux desktop icons and raster size variants
- z-app.ico: Windows icon containing multiple embedded sizes
- z-app.icns: macOS icon
- preview.png: light/dark preview

Fedora/Linux: use png/z-app-512.png as the Icon in your .desktop launcher (or install into ~/.local/share/icons/hicolor/512x512/apps/).
